## Правила для поля content (календарь)

- Заголовок h1: `# Название события`
- Извлеки дату, время и описание события из речи пользователя
- Если время не указано — укажи только дату
- Если событие повторяющееся — отметь это
- Структурируй: когда, где, кто участвует, что нужно подготовить

## Дополнительное поле calendar_event (ОБЯЗАТЕЛЬНО для календаря)

К стандартным полям из AGENT_CONFIG добавь в JSON как **отдельное поле верхнего уровня**:
```json
"calendar_event": {
  "date": "YYYY-MM-DD",
  "time_start": "HH:MM или null если время не указано",
  "duration_minutes": 60,
  "description": "Краткое описание для Google Calendar"
}
```

> ⚠️ **НЕ включай `calendar_event` в поле `content`** — только как отдельное поле JSON.
> Поле `content` содержит ТОЛЬКО markdown с frontmatter. `calendar_event` — соседнее поле.

### Правила извлечения даты и времени

- "завтра" → вычисли от текущей даты
- "в пятницу" → ближайшая пятница от текущей даты
- "через неделю" → текущая дата + 7 дней
- Если время не указано → time_start: null (событие на весь день)
- Если продолжительность не указана → duration_minutes: 60
- description → 1-2 предложения: место, участники, что нужно подготовить
